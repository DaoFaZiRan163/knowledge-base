# LoRA — 低秩自适应

## 核心定义

**LoRA (Low-Rank Adaptation)**：一种参数高效的微调方法，通过在原模型旁引入低秩矩阵来近似权重更新，从而只需训练少量参数就能实现模型微调。

**核心思想**：不直接更新原模型的所有参数，而是通过低秩分解来学习参数增量。

## 🎯 一句话总结

> **LoRA = 用低秩矩阵学习参数增量，只需训练0.1%参数就能微调大模型**

## 为什么需要LoRA

### 全量微调的问题

| 问题 | 说明 |
|------|------|
| 计算成本高 | 需要更新数十亿参数，GPU显存要求高 |
| 参数量大 | 训练时需要存储完整模型副本 |
| 多任务困难 | 每个任务需要完整微调，无法共享原模型 |
| 灾备恢复难 | 微调过程中出错难以回滚 |

### LoRA的解决方案

将权重更新 ΔW 表示为低秩形式：

```
ΔW = B × A，其中 B ∈ R^(d×r)，A ∈ R^(r×k)，r << min(d,k)

原权重: W0
更新后: W = W0 + ΔW = W0 + B × A

需要训练的参数: r × (d + k)，远小于 d × k
```

## 🏗️ LoRA 架构

```
┌─────────────────────────────────────────────────────────────┐
│                    LoRA 架构                                │
│                                                             │
│  输入 X                                                     │
│     ↓                                                       │
│  ┌─────────┐                                                │
│  │  原权重 W0 │  ────── 不更新 ──────→  冻结                │
│  └─────────┘                                                │
│     ↓                                                       │
│  ┌─────────┐     ┌─────────┐                                 │
│  │  低秩A   │ →   │  低秩B   │  →  ΔW = B × A              │
│  │ (r×d)   │     │ (r×k)   │                               │
│  └─────────┘     └─────────┘                                 │
│     ↓              ↓                                       │
│  W = W0 + ΔW = W0 + B × A                                   │
└─────────────────────────────────────────────────────────────┘

r = 秩（通常8-64），d = 输入维度，k = 输出维度
```

## 🔧 核心参数

| 参数 | 说明 | 常用值 |
|------|------|--------|
| r (rank) | 低秩维度，越大越接近全量微调 | 8, 16, 32, 64 |
| lora_alpha | 缩放因子，通常设为 2×r | 32, 64 |
| target_modules | 要应用LoRA的层 | q_proj, v_proj |
| lora_dropout | Dropout概率 | 0.05, 0.1 |

## 📊 参数量对比

```python
# 6.7B 参数模型示例
# trainable params: 4,194,304 || all params: 6,738,415,616 || trainable%: 0.0623

全量微调: 6,738,415,616 参数 (100%)
LoRA (r=16): ~4,194,304 参数 (~0.06%)
```

| 微调方法 | 可训练参数量 | 显存需求 |
|----------|-------------|----------|
| 全量微调 | 100% | ~80GB |
| LoRA (r=8) | ~0.1% | ~8GB |
| LoRA (r=64) | ~0.5% | ~12GB |
| QLoRA | ~0.1% (量化) | ~6GB |

## 💻 实战代码

### 基本使用

```python
from peft import LoraConfig, get_peft_model

# LoRA 配置
lora_config = LoraConfig(
    r=16,                    # 秩
    lora_alpha=32,           # 缩放因子
    target_modules=["q_proj", "v_proj"],  # 目标层
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 训练
trainer.train()
```

### 合并权重（推理时）

```python
# 训练完成后合并权重，推理时不需额外计算
merged_model = model.merge_and_unload()
```

## 🔄 LoRA vs 其他微调方法

| 方法 | 参数量 | 效果 | 适用场景 |
|------|--------|------|----------|
| 全量微调 | 100% | 最好 | 通用场景 |
| LoRA | 0.1-1% | 略低于全量 | 资源有限 |
| QLoRA | 0.1% (量化) | 接近LoRA | 消费级GPU |
| Adapter | 0.5-5% | 中等 | 多任务 |
| Prefix Tuning | <0.1% | 一般 | 少数据 |

## 💼 应用场景

### 1. 垂直领域微调

- 法律、金融、医疗等专业领域
- 只需要微调少量参数即可获得领域适配

### 2. 多任务学习

- 多个任务共享原模型
- 每个任务只保存LoRA权重（MB级别）
- 可动态加载/切换任务

### 3. 消费级GPU训练

- 7B模型用LoRA只需~8GB显存
- 在RTX 3090上即可训练

### 4. 快速迭代实验

- 轻松尝试不同超参数
- 快速A/B测试不同微调版本

## ⚠️ 注意事项

| 注意点 | 说明 |
|--------|------|
| r值选择 | r太小欠拟合，r太大接近全量微调 |
| 目标层选择 | 通常选Attention层(q/v proj) |
| 学习率 | LoRA通常用更高学习率(1e-3 ~ 1e-4) |
| 数据质量 | LoRA对数据质量更敏感 |
