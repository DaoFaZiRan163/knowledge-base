## 🔄 摄入流程

```
Obsidian 笔记 (.md)
    ↓
FDEKnowledgeIngester.process_source()
    ↓
RecursiveCharacterTextSplitter (chunk_size=1000, overlap=200)
    ↓
SiliconFlow API: Qwen3-Embedding-0.6B
    ↓
Qdrant fde_knowledge collection (upsert)
```

### 关键参数

- **Embedding 模型**: `Qwen/Qwen3-Embedding-0.6B` (SiliconFlow)
- **向量维度**: 1024
- **Chunk 大小**: 1000 字符
- **Chunk 重叠**: 200 字符
- **ID 生成**: `MD5(source_path)[:8] + "_" + chunk_index`

## 🔁 增量摄入逻辑

- **Upsert 机制**: 相同 ID 的 Chunk 会覆盖更新，不会重复创建
- **ID 计算**: `MD5(文件路径)[:8] + "_" + chunk_index`
- **更新场景**: 修改笔记内容后重新摄入，内容自动更新

---

## ⚠️ 注意事项

1. **Qdrant 服务**: 需要先启动 `vendor/qdrant/qdrant.exe`
2. **API 配额**: SiliconFlow 有免费额度限制，批量摄入注意配额
3. **编码问题**: 处理中文路径时需配置 UTF-8 输出
